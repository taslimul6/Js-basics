## 🚀 Getting Started

Clone the repo and run any file with Node.js:

```bash
git clone https://github.com/taslimul6/Js-basics.git
cd Js-basics
node array.js
```

## 🛠️ Requirements

- [Node.js](https://nodejs.org/) installed on your machine
